# Addon Maker by НсП

Браузерный конструктор меню для Minecraft Bedrock.

## Возможности
- Визуальное редактирование окна меню и кнопок.
- Открытие меню предметом, тегом игрока или обоими способами.
- Действия кнопок: сообщение, команда, выдача предмета и телепорт.
- Необязательные изображения кнопок.
- Экспорт проекта в JSON, скрипта в JS и готового архива **.mcaddon**.
- При сборке .mcaddon создаются Behavior Pack и Resource Pack с отдельными manifest.json.

## Совместимость
Сборка настроена под Minecraft Bedrock 1.21.51 и зависимости Script API `@minecraft/server 1.13.0` и `@minecraft/server-ui 1.3.0`. Другие версии могут требовать изменения зависимостей.

## Использование
Откройте `index.html` в браузере с интернетом (ZIP-библиотека загружается с CDN), настройте меню и нажмите **«Экспорт готового .mcaddon»**. После импорта файла в Minecraft активируйте Behavior Pack и Resource Pack в настройках мира. Если игра запросит разрешение для скриптов, включите его.

Экспорт собран автоматически; работоспособность в конкретном мире зависит от версии Minecraft и разрешений мира.
