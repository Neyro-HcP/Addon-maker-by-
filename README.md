# Addon Maker — Bedrock Workshop

Мобильный браузерный конструктор пакетов Minecraft Bedrock. Точка входа — `index.html`.

## Что можно собрать

- **Меню в игре:** редактировать заголовок, описание и кнопки; добавить изображения; открывать меню предметом, тегом или обоими способами; назначать кнопкам сообщение, команду, выдачу предмета или телепорт.
- **Свои предметы:** задать ID, имя, категорию, размер стака, прочность и PNG-значок.
- **Свои блоки:** задать ID, имя, категорию, время добычи, сопротивление взрыву, режим прозрачности и PNG-текстуру. Базовый генератор делает куб с одинаковой текстурой на всех сторонах.
- **Свои мобы:** базовый нейтральный гуманоид с собственной текстурой 64×64, здоровьем и скоростью движения.
- **Замена текстур:** добавить PNG по относительному пути в Resource Pack, в том числе для ванильных текстур, если путь точно совпадает с путём в используемой версии Minecraft.
- **Расширенные файлы:** добавлять и менять текстовые файлы BP/RP — JSON сущностей, рецепты, таблицы лута, функции `.mcfunction`, языковые файлы, анимации и другие ресурсы.
- **Импорт существующего аддона:** загружать `.mcaddon`, `.mcpack` или `.zip`, выбирать файлы из архива, редактировать текстовые JSON/JS/MCFUNCTION, удалять ненужные файлы и заменять бинарные ресурсы — текстуры PNG, звуки, модели и т. д.
- **Экспорт и перенос:** сохранять проект в браузере, экспортировать JSON, скачивать JS и собирать готовый архив `.mcaddon` с Behavior Pack и Resource Pack.

## Совместимость

Настройки сборщика ориентированы на Minecraft Bedrock 1.21.51 с зависимостями Script API `@minecraft/server 1.13.0` и `@minecraft/server-ui 1.3.0`. Другие версии могут требовать обновления зависимостей или форматов файлов.

## Как пользоваться

1. Откройте `index.html` в браузере с интернетом: архиватор JSZip загружается с CDN.
2. Настройте меню и нужные предметы, блоки, мобы или текстуры.
3. Чтобы изменить готовый аддон, импортируйте его архив в разделе **«Импорт и редактор готового аддона»**, выберите файл и сохраните изменения. Для PNG, моделей и звуков используйте замену выбранного файла.
4. Для новых предметов/блоков/мобов загрузите PNG в соответствующем разделе.
5. Нажмите **«Экспорт готового .mcaddon»**, импортируйте архив в Minecraft и активируйте оба пака в настройках мира. Если игра попросит разрешение для скриптов, включите его.
6. Сохраняйте копию проекта через экспорт JSON — изображения и импортированные ресурсы внутри проекта могут сделать файл большим.

## Важные ограничения

- Замена ванильной текстуры работает только при точном совпадении пути и имени файла. Неверный путь не заменит текстуру в игре.
- Для расширенного редактора формат и допустимые поля определяются Minecraft. Некорректный JSON или неподдерживаемый компонент может сломать соответствующую часть аддона.
- При импорте `manifest.json` и `scripts/main.js` пропускаются: манифесты создаются заново, а `scripts/main.js` генерируется из редактора меню. Остальные найденные файлы сохраняются в соответствующем BP/RP.
- Для ZIP-архивов без корректного `manifest.json` автоматическое определение, относится ли файл к BP или RP, может быть неточным.
- Генерируемый блок — простой куб с одной текстурой на все грани; сложные модели и отдельные текстуры граней нужно описывать отдельными ресурсами.
- Генерируемый моб — простая нейтральная гуманоидная модель. Анимации, звуки, дроп, особое поведение и сложную геометрию нужно добавлять через соответствующие файлы.
- Архив создаётся автоматически, но сборка **не означает, что каждый пользовательский JSON проверен игрой**. После импорта обязательно проверьте пак в тестовом мире и посмотрите журнал контента Minecraft при ошибках.
