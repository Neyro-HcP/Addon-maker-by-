Экспорт включает Behavior Pack, Resource Pack, манифесты и скрипт. Для этой сборки указаны @minecraft/server 1.13.0 и @minecraft/server-ui 1.3.0 (ориентир — Bedrock 1.21.51).

Готово к сборке.

Проект сохраняется в браузере. Экспортируй JSON как резервную копию.

Живой предпросмотр

Макет стандартного меню Minecraft Bedrock.

Информация

Заголовок, описание, названия кнопок и картинки обновляются сразу. Отдельные описания кнопок в стандартном ActionFormData Minecraft не поддерживаются.

Конструктор предметов

Создаёт новый предмет с PNG-значком, ID, названием, размером стака и прочностью. PNG до 2 МБ. Для сложных механик используй редактор файлов ниже.

Конструктор блоков

Создаёт кубический блок с одной текстурой на все стороны. Для отдельных текстур сторон и сложной геометрии используй расширенный редактор. Рекомендуется PNG 16×16, 32×32 или 64×64.

Конструктор мобов

Создаёт гуманоидного моба с ID, текстурой PNG 64×64, здоровьем, уроном и скоростью. Базовое поведение — охота на игроков. Для сложных моделей, анимаций, звуков и дропа используй JSON-файлы ниже.

Замена существующих текстур

Загружает PNG в путь Resource Pack. Для замены ванильной текстуры путь и регистр букв должны совпасть с путём в исходном паке Minecraft. Примеры: textures/entity/zombie/zombie.png, textures/entity/creeper/creeper.png, textures/items/diamond.png, textures/blocks/stone.png. Путь может различаться в разных версиях.

Расширенный редактор файлов BP / RP

Добавляй JSON сущностей, рецепты, таблицы лута, функции .mcfunction, языковые файлы, анимации и другие текстовые ресурсы. Путь задаётся относительно пака. Не добавляй сюда manifest.json и scripts/main.js — они создаются автоматически.
